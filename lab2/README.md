## Task 4 — Умножение матриц

**Условие:** написать программу умножения больших матриц. Сравнить время последовательной и параллельной версий на 2, 4 и 8 потоках.

**Исходник:** `lab2.cpp`

**Сборка (MSVC):**
    cl /openmp /EHsc /O2 lab2.cpp /Fe:lab2.exe

**Запуск:**
    lab2.exe <size> <threads>

**Примеры:**
    lab2.exe 2048 2
    lab2.exe 2048 4
    lab2.exe 2048 8

**Ожидаемый вывод:**
    n=2048 threads=2
    seq: ... s
    par: ... s
    speedup: ...x
    diff: 0.000000

**Пояснение:**
- `size` — размер квадратной матрицы (N×N);
- `threads` — число потоков для параллельной версии;
- `speedup = seq / par`;
- `diff` — суммарное расхождение результатов последовательной и параллельной версий (должно быть ≈ 0).
